# 🎬 Teleprompter Pro

**Teleprompter Pro** es una aplicación web minimalista y funcional desarrollada con **HTML5, CSS3 y JavaScript puro**, diseñada para ayudar a oradores, creadores de contenido y presentadores a leer sus guiones de manera fluida y profesional.  

Este proyecto fue desarrollado por **Ing. Franklin Gutierrez Arizaca** como parte de sus herramientas educativas y de apoyo tecnológico.  

---

## ✨ Características

- 📝 **Editor de texto enriquecido** con soporte para **negrita, cursiva y subrayado**.  
- 🎥 **Vista de teleprompter** con **scroll automático**.  
- ⏱ **Control de velocidad** ajustable en tiempo real.  
- ⏯ **Botones de Iniciar/Detener** y accesos directos de teclado:  
  - `Espacio` → Inicia/Pausa el scroll.  
  - `+ / -` → Aumenta o disminuye la velocidad.  
- 🖥 **Modo Pantalla Completa** para una experiencia limpia y profesional.  
- 🌙 **Cambio de Tema (claro/oscuro)** según el entorno de lectura.  
- 💾 **Guardado automático en LocalStorage** (tu texto se conserva al recargar).  
- ℹ️ **Modal "Acerca de" elegante** con créditos, contactos y enlaces.  
- 📤 **Opciones de compartir** (WhatsApp, Email, Copiar enlace).  
- 📱 **Diseño responsive** para usarse en escritorio y dispositivos móviles.
